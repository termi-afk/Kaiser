Kaiser

Das Strategiespiel von Stefan Maday für Windows 3.1, im Browser: das originale Programm, unverändert, mit Musik und Soundeffekten in 800×600.

Version
Größe
  • Beim ersten Start lädt der Browser rund 40 MB, danach geht es schneller.
  • Einstellungen und Spielstände bleiben in diesem Browser gespeichert (lokal, nicht auf einem Server).
  • Die Musik spielt ein Synthesizer im Browser, sie klingt daher anders als unter Windows.
  • Für Windows 10/11 gibt es auch einen Installer.
